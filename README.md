# Ernakulam Air Quality Monitor

A web application for visualizing air pollution concentrations
(NO₂, CO, SO₂) across Ernakulam district, Kerala using
Sentinel-5P TROPOMI satellite data via Google Earth Engine.

## Live Site
👉 https://[your-github-username].github.io/ernakulam-air-quality

## Features
- Interactive live map powered by Google Earth Engine
- NO₂, CO, SO₂ concentration visualization
- Pre-COVID, COVID, Post-COVID period comparison
- Rectangle drawing tool for area export
- High quality GeoTIFF export for QGIS
